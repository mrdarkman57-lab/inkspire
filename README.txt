InkSpire — Writer's Social Network & Studio (Upgraded)
======================================================

Open index.html in a modern browser. Internet access is recommended for Tailwind CSS, Font Awesome, and Google Fonts CDN assets.

Features:
- Explore feed with genre filters and search
- Publish writing, likes, comments, bookmarks, and share-copy action
- Writing Studio with 10 templates
- Local autosave and editable drafts
- Book/project organizer with chapter lists
- Word and character counts
- Quick formatting inserts
- Import and export .txt files
- Writer profile UI
- Dark mode
- Responsive desktop/mobile navigation

This is a front-end prototype. Content is stored in the browser's localStorage; it does not provide cloud sync, authentication, or real multi-user networking.
